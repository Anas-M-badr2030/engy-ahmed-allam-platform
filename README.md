# Engy Ahmed Allam - Beauty Specialist Platform

منصة إلكترونية متكاملة لحجز جلسات العناية بالبشرة وعرض الخدمات ومعرض الأعمال (قبل وبعد) مع لوحة تحكم إدارية كاملة للأخصائية **إنجي أحمد علام** بطنطا.

## المميزات الرئيسية
- **واجهة عربية فاخرة (RTL):** متوافقة مع الهوية البصرية الذهبية والداكنة ومتجاوبة بالكامل مع الهواتف.
- **نظام حجز ذكي من 4 خطوات:** اختيار الخدمة، تحديد اليوم والساعة المتاحة، إدخال بيانات العميلة، وتأكيد الحجز عبر واتساب.
- **معرض أعمال تفاعلي (قبل / بعد):** مع فلترة فورية حسب نوع الجلسة.
- **لوحة تحكم شاملة (`/admin/dashboard`):** متابعة مواعيد اليوم، إدارة الحجوزات، سجل العميلات، والتحكم في المواعيد المتاحة والمغلقة.

## التقنيات المستخدمة
- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Database:** Supabase (PostgreSQL)
- **Icons:** Lucide React
